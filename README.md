# Isaac Sharief for President

Static GitHub Pages campaign site for Isaac Sharief and the American Vanguard school party.

## Publish

Upload these files to a GitHub repository and enable GitHub Pages from the repository settings. `index.html` is the homepage.

## Before publishing

- Replace `assets/photo-required.svg` references with a real Isaac Sharief campaign photo.
- Add the real campaign email on `news.html` and `privacy.html`.
- Connect forms to a real form service if you need central signup records.
- Connect `donate.html` to an approved processor before collecting real money.

The current forms store demo entries in the visitor's browser so the site works without a backend.
